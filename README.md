# 🚀 AI Powered Swarm Pathfinding

## 📌 Project Overview
AI Powered Swarm Pathfinding is a full-stack web application that demonstrates intelligent pathfinding using the A* (A-Star) algorithm combined with AI-based explanation. The system allows users to define a grid/map, set start and end points, and visualize the shortest path along with a detailed explanation generated using AI.

This project showcases the integration of algorithms, artificial intelligence, and modern web technologies in a single platform.

---

## 🎯 Objectives
- Implement efficient pathfinding using A* algorithm  
- Visualize shortest path on a grid-based system  
- Provide AI-generated explanation for the computed path  
- Build a responsive and interactive web interface  
- Demonstrate full-stack development skills

## ▶️ How to Run the Project

### 1️⃣ Clone the Repository
```
git clone https://github.com/arniya2017-gif/ai-swarm-pathfinding.git
cd ai-swarm-pathfinding
```

### 2️⃣ Install Dependencies

#### Backend
```
cd backend
npm install
```

#### Frontend
```
cd ../frontend
npm install
```

### 3️⃣ Run the Application

#### Start Backend
```
cd backend
npm run dev
```

#### Start Frontend
```
cd frontend
npm start
```

## 🧠 How It Works
1. User creates or uploads a grid  
2. Start and end points are selected  
3. A* algorithm computes the shortest path  
4. Backend processes the path  
5. AI generates explanation  
6. Results are displayed on the UI
